Fluxygen: Assimbly, fully managed

Fluxygen is an integration platform built on Assimbly. Your Flows run on the same engine (Apache Camel and ActiveMQ), but Fluxygen hosts, secures, monitors and upgrades it for you. It also adds the tools teams need to run integrations in production.

Upgrade in three steps

  1. Try Fluxygen Start with Try it yourself on fluxygen.com.
  2. Export your Flows On the Flows list, Export for Fluxygen makes a zip that Fluxygen imports.
  3. Import and go live Import the zip in Fluxygen with your passphrase, then set up Brokers, Certificates and users there.
